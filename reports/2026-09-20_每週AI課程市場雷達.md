## 深拆五案

### 1. 先行智庫 Agent in a Box

- 證據：活動頁列 2026-10-01、14:00-17:00，主軸是地端解決方案、機密資料、部署環境、使用成本與既有流程整合。
- 包裝結構：趨勢與應用方向、AI 工具與 Agent 差異、企業流程分析、現場建立 Agent、企業導入案例。
- 可借鑑：它把「做 Agent」放回企業導入條件：資料在哪裡、部署在哪裡、成本誰負責、流程怎麼接。
- 不可照搬：平台展示與 Windows 筆電條件不適合成為 Mandy 主課門檻。
- Mandy 最小驗證：主管戰情室新增「Agent 導入控制點與例外升級卡」。

### 2. 天下學習陪跑版 AI 雙課套組

- 證據：頁面列楊立偉《給超級主管的 AI 管理課》、黃琇琳《AI Agent 零基礎打造個人工作流》與《90 天 AI 陪跑》，期間 2026-06-26 至 2026-09-24。
- 包裝結構：主管管理課、個人工作流課、90 天直播與共學社群、每週趨勢觀點。
- 可借鑑：市場已經把「課後陪跑」當作 AI 導入產品的一部分，這比加長單堂課更貼近行為改變。
- 不可照搬：陪跑成本、社群營運與講師資源需另估，不應直接變成標準課程承諾。
- Mandy 最小驗證：先把 90 天做成使用紀錄卡與回診題，不立即承諾完整陪跑產品。

- Mandy 最小驗證：每個 Agent 候選題都先問 build/buy/partner 與「不做」條件。

## 本週三個包裝模式

1. **從做出 Agent 到導得進企業**：新訊號不再只賣原型，而是開始談部署、資料、成本、流程整合與治理。
2. **從人治覆核到控制點設計**：主管課的語言從 decision rights 前進到 review thresholds、audit trails、incident response 與例外升級。
3. **從單堂課到 90 天節奏**：市場把 AI 導入視為持續校準，課程、共學、部署計畫與回診機制開始被包成一個產品。

### 個人 AI 工作台

- 保持主定位：從零散使用 AI，升級成可重複、可檢查的個人工作系統。
- 本週建議新增候選模組：「Agent 工作流上線驗收卡」。
- 不建議把主課改成 n8n、Zapier、MaiAgent 或特定 Workspace Agent 操作班。

### 企業／主管戰情室

- 保持主定位：資料、訊號、決策、行動追蹤的管理閉環。
- 本週建議新增候選模組：「Agent 導入控制點與例外升級卡」。
- 不建議改成資安、法遵或大型 IT 架構課；Mandy 版本應聚焦主管可判斷的控制點與升級節奏。

## 課程卡草案

### 推薦課名

### 備選課名

- 做出 Agent 之後：主管的資料安全、覆核與上線驗收課
- Agent 工作流上線驗收：從雙資料測試到 90 天使用紀錄

### 2 / 4 / 7-8 小時延展

- 2 小時：完成一張 Agent 控制點地圖，標出資料、工具、AI、人工覆核與例外升級。
- 4 小時：加入雙資料測試、錯誤分類、紀錄保存、build/buy/partner 與 30 天試行節奏。
- 7-8 小時：加入 stakeholder buy-in、技術與組織治理並行、90 天部署路線與停損／擴大判斷。
